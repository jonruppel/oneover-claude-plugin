# OneOver for Claude

Official Claude plugin for [OneOver](https://oneover.com): image, video, and audio generation and multi-model chat over MCP.

```
export ONEOVER_API_KEY=oo_live_...
/plugin marketplace add jonruppel/oneover-claude-plugin
/plugin install oneover@oneover
```

Get a key at https://oneover.com/developers/dashboard. Docs: https://oneover.com/developers/mcp
