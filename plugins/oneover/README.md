# OneOver for Claude

Official plugin. Adds the OneOver MCP server and a skill that teaches Claude when and how to use it.

```
export ONEOVER_API_KEY=oo_live_...
/plugin marketplace add jonruppel/oneover-claude-plugin
/plugin install oneover@oneover
```

Key: https://oneover.com/developers/dashboard. Docs: https://oneover.com/developers/mcp
